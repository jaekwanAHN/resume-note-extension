# 이력 메모

현재 웹페이지 옆의 Chrome 사이드 패널에 메모를 띄우는 Manifest V3 확장 프로그램입니다. Chrome 116 이상이 필요합니다. 빌드와 서버, 로그인 없이 사용합니다.

## 설치

1. Chrome 주소창에서 `chrome://extensions`를 엽니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 이 폴더(`/home/ggstork/projects/resume-note-extension`)를 선택합니다.
5. 툴바의 퍼즐 아이콘에서 **이력 메모**를 고정합니다.

## 사용

- 확장 아이콘을 누르면 현재 페이지 옆에 메모 사이드 패널이 열립니다. 페이지나 탭을 이동하지 않습니다. 패널 상단의 × 버튼으로 닫습니다. 패널의 좌우 위치는 Chrome 설정을 따릅니다.
- 개인정보 / 학력 / 군 복무 / 경력 / 기타 탭에서 값을 입력합니다. 변경 사항은 자동 저장됩니다.
- **기록 추가**로 학교, 회사, 자격증 등을 여러 개 관리하고 기록 제목을 수정합니다.
- 값 옆의 **복사**를 누르고 지원서에 붙여 넣습니다. 날짜는 증빙 자료를 확인해 직접 입력합니다. 날짜 검증이나 자동 입력은 아직 하지 않습니다.
- **접기**로 메모 내용을 숨길 수 있습니다. 패널 너비는 Chrome 패널 경계를 드래그해서 조절합니다. 페이지를 스크롤해도 메모는 유지됩니다.
- **백업 내보내기 / 가져오기**로 JSON 파일을 저장·복원합니다. 가져오기는 확인 후 현재 전체 기록을 교체합니다.
- 새로고침 또는 다른 페이지로 이동해도 사이드 패널은 유지됩니다.
- 웹페이지에 패널을 삽입하지 않으므로 Chrome 내부 페이지에서도 별도 메모 탭으로 이동하지 않습니다.

## 데이터와 권한

데이터는 `chrome.storage.local`에 저장하며 서버 전송, 분석, 계정 동기화는 없습니다. 확장 프로그램을 삭제하거나 브라우저 프로필을 지우면 데이터가 사라질 수 있으므로 백업을 보관하세요. 로컬 저장소와 백업 JSON은 별도 암호화하지 않습니다.

메모 UI는 Chrome이 제공하는 확장 프로그램 사이드 패널에서 실행됩니다. 저장소는 `TRUSTED_CONTEXTS`로 제한합니다.

- `storage`: 메모 저장.
- `sidePanel`: 현재 페이지 옆에 메모 표시.
- `clipboardWrite`: 사용자가 누른 값 복사. 클립보드 읽기는 하지 않습니다.

여러 패널을 열면 저장된 변경을 반영합니다. 두 창에서 정확히 동시에 수정할 경우 마지막 저장이 우선하므로 편집은 한 창에서 진행하세요.

## 개발 및 확장

- `background.js`: 아이콘 클릭 시 사이드 패널 열기 설정과 저장소 접근 제한.
- `memo.html`, `memo.css`, `memo.js`: 메모 편집 UI, 복사, 백업.
- `model.js`: 버전이 있는 문서 구조와 백업 검증. 각 기록에 분류, 각 필드에 고유 ID / 이름 / 값이 있습니다.

향후 DOM 분석 모듈에서 입력 요소의 label, name, autocomplete 등을 후보 필드와 매칭하고, 사용자 확인 후 선택한 입력 요소에 값을 넣는 모듈을 추가할 수 있습니다. 현재 버전에는 DOM 분석 및 자동 입력이 포함되어 있지 않습니다.

```sh
npm run check
npm test
```

수동 확인: 일반 HTTPS 사이트에서 아이콘 클릭 시 현재 URL 유지 및 사이드 패널 열기/닫기, 페이지 이동 중 유지, 접기/펼치기, 입력 후 새로고침 및 재열기, 복사/붙여넣기, 복수 학교·회사 추가, 삭제 취소, 백업 복원, 잘못된 JSON 거부, 좁은 창에서 표시, Chrome 내부 페이지에서 사이드 패널 열기를 확인합니다.

API 참고: [Chrome Side Panel](https://developer.chrome.com/docs/extensions/reference/api/sidePanel), [Chrome storage](https://developer.chrome.com/docs/extensions/reference/api/storage).

## 기존 설치 업데이트 (WSL + Windows Chrome)

`chrome://extensions`에서 **이력 메모** 카드의 새로고침 버튼(↻)을 누릅니다. 기존 메모는 유지됩니다. Windows 폴더에 복사해서 설치했다면 수정된 파일을 해당 폴더에도 복사한 다음 새로고침하세요. 삭제 후 재설치할 필요는 없습니다.
